# universidade-brasileira-livre

## 🎓 Jornada em Ciência da Computação - UBL

Este repositório é dedicado ao acompanhamento do meu progresso no currículo da **Universidade Brasileira Livre (UBL)**. Aqui, documento meus estudos teóricos, exercícios práticos e projetos desenvolvidos ao longo dessa trilha inspirada na OSSU.

Meu objetivo é construir uma base sólida em fundamentos de computação para complementar minha formação acadêmica em GTI e fortalecer minha transição de carreira para Cybersecurity e Desenvolvimento de Software.
